# Stack Lang

Учебный проект: небольшой язык выражений и операторов, компилятор в байт-код
стековой машины, пошаговая виртуальная машина и GUI-визуализатор.

Нужен Python 3.10+ (проект проверялся на 3.13).

Проект специально разделён на два независимых слоя:

- **core** — язык, компилятор, байт-код и VM;
- **gui** — Tkinter-представление, которое только читает состояние и вызывает
  методы контроллера. Логика языка в UI не вшита, поэтому GUI можно заменить
  на PySide6, web или что угодно без переписывания компилятора.

## Быстрый старт

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m gui
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m gui
```

`tkinter` входит в стандартную библиотеку Python. На Linux может понадобиться
системный пакет `python3-tk`.

## Что уже работает

### Язык

- целые десятичные литералы (`42`, `007`);
- вещественные литералы (`1.5`, `1.5f`, `1.5d`, `1e3`);
- строковые литералы (`"текст"`, `'текст'`);
- идентификаторы, включая Unicode;
- арифметика: `+`, `-`, `*`, `/`, `%`, `^`;
- целочисленное деление с усечением к нулю и остаток в стиле C;
- постфиксный факториал `!`;
- унарные `+`, `-`, `!`;
- сравнения: `<`, `>`, `==`, `!=`, `<>`, `<=`, `>=`;
- логические `&&`, `||` (результат `0`/`1`);
- скобки;
- вызовы встроенных функций: `abs`, `min`, `max`, `sqrt`, `resize`;
- преобразования типов: `int(x)`, `float(x)`, `double(x)`, `string(x)`;
- вывод на экран: `print(...)`;
- пользовательские функции: `func int f(int a) { return a; }`, вызов `f(1)`,
  рекурсия, `return`;
- запуск функции в фоне: `go f(1);` и `go worker = f(1);`;
- ожидание и остановка горутин: `sync()`, `sync(имя)`, `kill()`, `kill(имя)`;
- объявления `int x;`, `float x;`, `double x;`, `string x;`;
- типизированные массивы: `int a[3];`, `float a = [1.0, 2.0];`,
  `string s[2];`, чтение и запись `a[i]`, изменение размера через
  `resize(a, n)`;
- присваивание `имя = выражение;`;
- выражения-операторы;
- `if` / `else if` / `else`;
- `while`;
- блоки `{ ... }`, в том числе как самостоятельный оператор.

### Типы

Скалярные типы: `int`, `float`, `double`, `string`. Массивы типизированы по
элементу: `int[]`, `float[]`, `double[]`, `string[]`.

Числовые типы упорядочены по точности: `int < float < double`. Проверка типов
выполняется **на этапе компиляции**:

- переменную нужно объявить (`int x;`) до первого использования — иначе
  «Переменная 'x' не объявлена»;
- повторное объявление — «Переменная 'x' уже объявлена»;
- тип выражения должен подходить к типу переменной — иначе «Нельзя присвоить
  значение типа int[] переменной 'x' типа int»;
- **неявное расширение разрешено** (`int` → `float` → `double`), а сужение —
  нет: `float x = 1.5;` ошибка, нужно `float x = 1.5f;` или `float x = float(1.5);`;
- массив нельзя использовать в арифметике — «Операция '+' не применима к
  массиву»;
- строки можно только складывать (`"a" + "b"`) и сравнивать; строки и числа
  смешивать нельзя;
- индекс массива должен быть `int`, а индексировать можно только массив;
- условия `if` / `while` должны быть числами.

Литералы: `42` — `int`, `1.5` и `1e3` — `double`, `1.5f` — `float`,
`1.5d` — `double`, `"текст"` — `string`. Явные преобразования: `int(x)`,
`float(x)`, `double(x)`, `string(x)`.

Областей видимости нет: объявление действует до конца программы. Поэтому
переменную, нужную внутри цикла, объявляют **до** цикла, а объявлять
переменные внутри тела цикла запрещено.

### Функции и горутины

Функция объявляется словом `func`, тип возврата и параметры типизированы:

```
func int add(int a, int b) {
    return a + b;
}

int x = add(1, 2);      // x = 3
```

У функции **своя область для объявлений**: параметры и объявленные внутри
переменные не видны снаружи. Глобальные переменные, наоборот, **видны внутри
функции** и могут изменяться; локальное имя перекрывает глобальное.

```
int n = 5;
int result = 1;
int i = 1;

func int fact() {
    while i <= n {
        result = result * i;
        i = i + 1;
    }
    return result;
}

int x = fact();     // x = 120
```

Два порядка ограничены одноходовым компилятором: функцию нужно **объявить до
первого вызова**, а глобальную переменную — **до функции**, которая её
использует. Рекурсия работает.

Функцию можно запустить **в фоне** — как горутину:

```
go count(1000);            // анонимная
go worker = count(1000);   // именованная

sync();          // дождаться всех горутин
sync(worker);    // дождаться одной
kill();          // остановить все
kill(worker);    // остановить одну
```

Горутина выполняется в отдельном потоке: у неё свои переменные, но общий
с программой вывод — `print` из горутины виден и в CLI, и в GUI. `sync()`
не блокирует интерфейс: он опрашивает состояние горутин между шагами.

`print` печатает значения: в CLI — на stdout, в GUI — в панель вывода.
Аргументы печатаются через пробел, каждый вызов `print` — отдельной строкой.

Пример:

```text
int n = 5;
int result = 1;
int i = 1;
while i <= n {
    result = result * i;
    i = i + 1;
}
print("факториал", n, "равен", result);
```

Массивы:

```text
int squares[5];
int i = 0;
while i < 5 {
    squares[i] = i * i;
    i = i + 1;
}
```

Вещественные числа и строки:

```text
double pi = 3.14159;
float half = 0.5f;
string greeting = "привет";
string name = "мир";
print(greeting + ", " + name + "!");
print("площадь:", pi * 2.0 * 2.0);
```

### Компилятор и VM

Компилятор однопроходный: разбирает символы исходника и сразу выпускает
байт-код. AST не строится, лексера нет — это осознанное упрощение для
учебной задачи про стековую машину.

Опкоды: `PUSH`, `LOAD`, `STORE`, `DECL`, `NEWARR`, `MKARR`, `INDEX`, `SETIDX`,
`POP`, `NEG`, `NOT`, `JZ`, `JMP`, `CALL`, `FACT`, `ADD`, `SUB`, `MUL`, `DIV`,
`MOD`, `POW`, `AND`, `OR`, `LT`, `GT`, `EQ`, `NE`, `LE`, `GE`.

`Machine` умеет выполнять код по одной инструкции (`step`), целиком (`run`),
сбрасываться (`reset`) и отдавать снимок состояния (`snapshot`). Это и есть
точка, через которую GUI делает дебаггер.

### GUI

Запуск:

```bash
python -m gui
```

Что есть:

- редактор исходника с подсветкой текущей строки;
- режим «Программа» / «Выражение»;
- байт-код с PC, операндом и номером строки;
- подсветка текущей инструкции;
- стек с вершиной сверху;
- таблица переменных (имя, объявленный тип, значение);
- таблица горутин (имя, состояние, число шагов);
- панель вывода и ошибок;
- запуск, пауза, шаг, сброс, выбор скорости;
- брейкпоинты двойным кликом по строке байт-кода;
- примеры программ;
- открытие и сохранение `.lang`-файлов.

Горячие клавиши:

| Клавиша | Действие |
|---|---|
| `F5` | запуск / продолжение |
| `F6` | пауза |
| `F10` | один шаг |
| `Ctrl+Enter` | компиляция |
| `Ctrl+R` | сброс |

### CLI

```bash
python stack_compiler.py --run "1 + 2 * 3"
python stack_compiler.py --run "x=41" "x + 1"
python stack_compiler.py --run "int i = 0; while i < 3 { i = i + 1; }"
python stack_compiler.py --run 'print("привет");'
python syntax_check.py "a + b * (c - 1)"
```

Переменные, переданные как `имя=значение`, компилятору известны заранее:
они считаются уже объявленными типа `int`.

Граница слоёв: `gui.controller.DebugSession` — единственное место, где UI
встречается с core. Контроллер не импортирует Tkinter, поэтому его поведение
тестируется обычным pytest. `gui.app` не содержит правил языка.

## Известные ограничения и TODO

Язык:

- области видимости нет: `{ }` не создаёт область, объявление действует до
  конца программы; объявлять переменные внутри тела цикла запрещено;
- нет типа `bool`: логические операции и сравнения дают `int` (`0`/`1`);
- `float` и `double` различаются только статически (неявное сужение
  запрещено, литерал `1.5f` — `float`, `1.5` — `double`), в рантайме оба
  хранятся как 64-битное число — 32-битная точность `float` не эмулируется;
- массивы динамические и одномерные; границы индекса проверяются в runtime,
  размер массива — тоже;
- функцию нужно объявить до первого вызова; вызов раньше объявления —
  ошибка компиляции;
- объявлять функцию можно только на верхнем уровне программы;
- `sync()` ждёт завершения горутин, но если горутина зациклена, её нужно
  останавливать через `kill()`;
- нет комментариев;
- нет `print`/`input` и строк;
- `&&` и `||` имеют одинаковый приоритет и не замыкаются коротко;
- нет `break`/`continue`/`for`;
- `^` неассоциативен (`1 ^ 2 ^ 3` — ошибка).

Инфраструктура:

- `syntax_check.py` пока не полностью повторяет грамматику компилятора
  (например, не знает `int`, массивы, вызовы функций и `^`);
- брейкпоинты в GUI ставятся по инструкциям, а не по строкам исходника;
- GUI не умеет step over/into: пользовательских функций пока нет;
- нет CI и автоматического coverage-порога.

Ближайший порядок работ:

1. Синхронизировать `syntax_check` с компилятором.
2. Добавить области видимости (сейчас объявление действует до конца программы).
3. Добавить пользовательские функции и кадры вызова.
4. Добавить комментарии и `print`.
5. Добавить source-level брейкпоинты и step over.
6. Подключить CI и coverage-порог.
